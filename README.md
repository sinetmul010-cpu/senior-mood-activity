# ☀️ 마음따라 춤따라 (Senior Mood & Activity Web App)

> **"오늘 내 마음에 꼭 맞는 활력을 선물하세요"**  
> 60~70대 시니어를 중심으로 모든 분들이 따뜻하고 쉽게 사용할 수 있는 어르신 맞춤형 생활 활동 & 댄스 추천 모바일 웹앱입니다.

---

## 🌐 라이브 배포 주소
- **웹앱 서비스 URL**: [https://senior-mood-activity.vercel.app](https://senior-mood-activity.vercel.app)
- **프런트엔드 배포**: Vercel CLI 프로덕션 배포 완료
- **데이터베이스 배포**: Supabase CLI 마이그레이션 배포 완료 (`gsstmtphlmbzhwrsiexr`)

---

## ✨ 핵심 기능 안내

1. **기분별 즉시 실천 활동 추천 (7개 기분)**
   - 기분이 좋아요 / 조금 우울해요 / 스트레스가 많아요 / 지루하고 무료해요 / 마음이 편안해요 / 누군가와 함께하고 싶어요 / 활력을 얻고 싶어요
   - 준비물이나 비용 없이 지금 바로 실천할 수 있는 활동 3가지 + 어울리는 댄스 + 추천 이유
   - 화면 이동: '다른 활동 추천받기' (첫 화면으로 복귀), '댄스 프로그램 알아보기'

2. **보조 프로그램: 댄스 소개 & 상담 연계**
   - 스포츠댄스, 웰빙댄스(사교댄스), 포크댄스 카드
   - 각 카드 터치 시 상담 영역으로 부드럽게 이동

3. **전화 상담 & 카카오톡 문의 (안전 장치 탑재)**
   - 아직 실제 연락처가 입력되지 않은 상태(`[상담 전화번호 입력]`, `[카카오톡 채널 주소 입력]`)에서는 엉뚱한 곳으로 연결되지 않도록 친절한 안내 팝업을 표시합니다.
   - 나중에 실제 번호/주소가 등록되면 스마트폰 `tel:` 통화 및 카카오 채널로 바로 연결됩니다.

4. **구글 로그인 & 관리자 회원 승인 시스템**
   - 구글 간편 로그인 지원 (Supabase Auth 연동)
   - 관리자 전용 회원 승인 페이지 (`/admin` 뷰):
     - 가입한 회원 목록 확인
     - 승인/승인 대기 원클릭 토글
     - **승인된 회원만 활동 나눔터에 글을 작성하거나 삭제할 수 있는 권한 부여**

5. **Anti-AI 인간 중심 디자인 스킬 적용**
   - 차가운 회색 박스 대신 따뜻한 크림/웜베이지 톤 컬러 팔레트
   - 20~24px 이상의 시원한 글씨와 70px 이상의 큼직한 터치 타겟
   - 부드러운 햅틱 감성 인터랙션과 높은 명도 대비

## 💻 내 컴퓨터에서 실행하기 (로컬 실행)

초보자분들도 더블 클릭 한 번으로 실행할 수 있도록 `run.bat` 파일을 제공합니다:

1. **원클릭 실행**: `run.bat` 파일 더블 클릭
2. **또는 터미널 실행**:
   ```bash
   npm run dev
   ```
3. 브라우저에서 `http://localhost:5173` 접속
